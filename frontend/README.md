# Stardex Dashboard

Placeholder for the Stardex web dashboard (React + Vite + Tailwind) — the
website for browsing indexed contracts and events.

Scaffolding this app is tracked as **backlog issue #23** in
[`../docs/BACKLOG.md`](../docs/BACKLOG.md). It's intentionally left empty for
now so a contributor can pick it up as a `good first issue`.

Once scaffolded:

```bash
pnpm --filter @stardex/frontend dev
```
